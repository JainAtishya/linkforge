# LinkForge

A production-oriented URL shortener built to explore backend engineering concepts by building a real-world system.

The goal of this project is not only to create shortened links, but to understand how backend systems are designed, optimized, and scaled.

## Tech Stack

### Backend

* Node.js
* Express.js
* MongoDB
* Redis

### Frontend

* React 

## Features

Currently in development:

* User authentication
* URL shortening
* Custom aliases
* URL expiration
* Password protected links
* Click analytics
* QR code generation
* Redis caching
* Asynchronous analytics processing

## Architecture

The project follows a modular backend architecture with separate layers for:

* Routes
* Controllers
* Services
* Database models
* Middleware

## Learning Goals

This project is being built to understand:

* REST API design
* Authentication and authorization
* Database modeling
* Caching strategies
* Event-driven architecture
* Performance optimization
* Production deployment practices
